01 / OVERVIEW

Critical experience becomes a learning loop.

DriveFoundry couples what the system learns from a scene with how the model decides what to compute next. A shared scene–candidate record keeps evidence, behavior and consequence aligned across data production, training and inference.

DATA ENGINE

Structured causal supervision

Failure mining finds rare interactions. VLM-assisted annotation proposes World–Policy–Value records, experts correct the decision-critical relations, and quality gates publish reusable supervision.

Follow the data loop →

MODEL ENGINE

Value-guided cognition

Xiaomi-Drive-o1 shares one vision–language backbone across Perception, Causation, Action, World and Value. A value-of-computation head spends extra reasoning only when it can improve the decision.

See adaptive inference →

02 / DATA ENGINE

World, Policy and Value in one scene–candidate record.

The record keeps the factual scene, the candidate behavior and the consequence assessment together. Multiple candidates can share one scene, making counterfactual comparison explicit instead of post-hoc.

W

World

Evidence, object states, event segments and interaction relations with valid time and provenance.

P

Policy

Semantic intent, lateral and longitudinal decisions, and their continuous motion realization.

V

Value

Safety, comfort, efficiency, compliance and navigation following, plus observed and counterfactual outcomes.

01 / CAUSAL RECORD

Factor → decision

Each causal pair binds a critical factor to a decision instance, with MOTIVE or CONSTRAINT role, evidence and valid time. This lets the model distinguish why an action is required from what merely limits it.

02 / QUALITY LOOP

Propose → correct → learn

VLM proposals are checked for factual grounding, temporal alignment and candidate consistency. Verified failures revise both the published record and the annotation model used for the next batch.

03 / MODEL ENGINE

One backbone. Five interfaces. Shared latent state.

Block-wise latent refill passes realized upstream outputs into downstream task blocks. The same candidate identity is preserved across planning, future prediction and evaluation.

P

Perception

Objects, geometry, detection, segmentation and depth from the current scene.

C

Causation

Critical factors, roles and factor–decision relations grounded in evidence.

A

Action

Semantic decisions and a continuous 6.4 s trajectory at 10 Hz.

W

World

Candidate-conditioned future visual tokens for consequence checking.

V

Value

Safety, comfort, efficiency, compliance and navigation value, plus VOC.

Latent refillRealized upstream task tokens are refilled into downstream blocks instead of being decoded as disconnected text.
Candidate identityWorld predicts the future conditioned on the same candidate that Value scores.
Shared trainingJoint supervision aligns gradients while retaining task-specific outputs and budgets.

04 / ADAPTIVE INFERENCE

Reason only as far as the decision requires.

Inference starts with a fast Action–Value path. A value-of-computation (VOC) head estimates whether an additional task or latent budget is worth its incremental compute, latency and memory cost.

FAST PATH / SYSTEM 1

Action → Value

Generate and score a candidate from the shared driving knowledge already encoded in the backbone.

TARGETED ESCALATION

Perception → CoC → Action

Refill scene evidence and causal constraints before regenerating the candidate.

FULL VERIFICATION

... → World → Value

Predict candidate-conditioned future visual evidence, then rank admissible trajectories with a fallback policy.

COMPUTELATENCYMEMORYRESERVED CONTROL TIMEVOC selects the next useful block, not the longest path.

05 / TRAINING

A common interface from language to behavior.

Training moves from broad driving knowledge to structured task supervision and then to feedback that balances behavior quality with computation. Task supervision remains available during post-training.

STAGE 01

Pretraining

Language, discrete visual sequences and basic driving knowledge establish a shared representation.

STAGE 02

Mid-training / SFT

World, Causation, Perception, Action and Value receive structured supervision from the records.

STAGE 03

Post-training

Rule rewards and policy optimization improve Action; Value and VOC learn candidate quality and computation benefit.

07 / FIELD TEST

From benchmark records to the road.

The tested vehicle configuration ran the inference pipeline at 10 Hz on an NVIDIA RTX 4090. The paper reports eight real-vehicle Chain-of-Causation visualizations, used here as qualitative evidence.

+

Qualitative cases are not a substitute for a frozen deployment protocol; they show how evidence, causal attribution and action remain connected in the tested loop.
